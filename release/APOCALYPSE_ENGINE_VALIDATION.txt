8. KNOWN ISSUES
------------------------------------------------------------------------------
  - Balance (boss health tiers, damage, event spawn rates) is tuned on paper and in simulation only; expect tuning after real play.
  - Boss movement uses vanilla navigation components; on very rugged terrain bosses may path poorly (scripted leash returns them to the arena).
  - Event and Expanse fog uses /fog push per player; it is re-synchronised on join, dimension change and event start/end.
  - The Shattered Expanse is generated by script around players: islands appear a moment after arrival on slow devices (time-budgeted jobs).
  - Ticking-area capacity is shared with other add-ons/commands; if none is free the first Expanse visit asks the player to retry.
  - Pre-built structures (Nexus Shrine, Colossus Altar, ruins) are placed via the structure manager; they were generated by our own .mcstructure writer and verified by our reader, not opened in a game editor.
  - Creator Tools warnings listed in section 5 are tool-side limitations/strictness, documented rather than worked around.

9. NOT IMPLEMENTED / OUT OF SCOPE
------------------------------------------------------------------------------
  - Custom shaders/GLSL/HLSL, RenderDragon material overrides and custom post-processing: not possible for Bedrock add-ons.
  - A biome-based dimension generator: Bedrock only offers script-registered custom dimensions with the void generator, so all Expanse terrain is script-built (documented as such, not presented as engine worldgen).
  - Custom music tracks and voiced dialogue.
  - Localisation beyond en_US.
  - Marketplace-style world template / skin pack.

11. GRAPHICS / SHADER LIMITATIONS
------------------------------------------------------------------------------
  - Bedrock add-ons cannot ship shaders. This project contains no shader code and does not modify the game.
  - Visual quality comes from: original HD textures (1x in the base pack, 2x/4x in subpacks), emissive glow layers using the vanilla entity_emissive_alpha material, PBR texture sets (MER + normal maps), custom particles, per-event fog, and Vibrant Visuals atmospherics/lighting/color-grading JSON configs.
  - PBR texture sets, volumetric fog and the Vibrant Visuals configs only take effect when the device supports and the player enables Vibrant Visuals; on other devices the same packs render with standard (non-PBR) graphics.
  - The resource pack declares the 'pbr' capability; subpacks: Potato (sparse particles, base textures), Balanced (2x textures + PBR), Enhanced (4x textures + PBR, dense particles).
