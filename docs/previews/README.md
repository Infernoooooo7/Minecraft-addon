# Previews

Renders of the shipped models with the **Balanced** subpack textures, produced with Mojang's
Minecraft Creator Tools 0.20.0 (`mct rendermodel <geometry> --no-vanilla`, software WebGL) and
assembled into sheets; item and block sheets are the pack textures enlarged 4× (nearest neighbour).
They show base color only — emissive glow layers, PBR materials and particles appear in-game.

* `bosses.png` — the four bosses
* `bestiary.png` — bosses, creatures, hazards
* `items.png` — all 41 item icons
* `blocks.png` — all 14 blocks
